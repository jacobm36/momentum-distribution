# Ultimate Double Dragon 3 — Player Guide

Connect your 8BitDo before opening the game, using the same connection mode as your working setup when possible. Jacob’s working fullscreen/shader/controller preset is provided for a fresh install; your existing settings always win.

Fresh installs use `~/Games/ultimate-double-dragon-3`. Keep `Saves/` backed up. Repair and game-only removal preserve customized CFG and progress and keep the shared engine. If a managed PAK or launcher was edited, removal stops rather than deleting those edits. This installer has not certified target gameplay.

## Controls

The captured preset is the authoritative working configuration. This guide does not invent an action-to-button map or assume the Marvel bindings apply to UDD.

If the controller differs, open Control Options, enable gamepads and enter Player 1. Highlight an action with the keyboard, press Enter to start reassignment, release Enter, then press the desired controller button or direction. Choose OK to save. A different pad mode or Bluetooth connection can change identifiers; remap as needed. Keyboard F12 takes screenshots.

## First play check

Check that the game opens with your fullscreen, shader and controller preset. Test movement, attacks, jump, block, style switching, pause and menu selection. Exit through the game menu and relaunch to confirm settings persist. Avoid force-killing the game while saving.

The next compatibility check is completing a stage and entering the next one; this has not yet been confirmed. If something fails, retain `Logs/OpenBorLog.txt` and `Logs/ScriptLog.txt` from the installed game directory. Confirm controller input, audio, progression and clean relaunch before marking this installation ready in Momentum.
