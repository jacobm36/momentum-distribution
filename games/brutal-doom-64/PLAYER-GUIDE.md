# Playing Brutal Doom 64

Launch **Brutal Doom 64** from Momentum or the Applications menu after installation with a supporting runner. Start a new single-player game and confirm the Brutal Doom 64 title and first map. Check Options/Controls for movement, mouse aim and firing; your existing UZDoom settings are preserved.

Confirm that music and the announcer load. Change resolution/fullscreen through the game's video settings if desired. Save a game, exit normally, relaunch from the same entry and load the save before marking setup complete.

The upstream README advises disabling Enhanced Night Vision when moving to a different engine setup. This package does not silently change that option. Older mod-version saves may be incompatible; keep them and start a new game if needed. See the original README in `upstream/` for credits and optional blood/performance console settings.

Doom II appearing without the mod usually means the four mod files or launch order are wrong. Missing-content errors can indicate sandbox access or a moved IWAD. Use Momentum's Verify, then explicit Repair; edited files are preserved and require reconciliation. Uninstall keeps your Doom II copy and UZDoom settings/saves.
