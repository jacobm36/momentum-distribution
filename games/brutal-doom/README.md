# Brutal Doom

Classic Doom II. A whole lot more impact.

## Bring your game

Select a folder containing your licensed **DOOM2.WAD**. All guide-selected mod content and artwork are bundled; no mod downloads or engine choices. Commercial base data is not included.

## Install

**Add game > Brutal Doom > Choose folder > Review > Install.** Momentum prepares missing UZDoom after separate approval and copies your base files without changing originals.

Default destination: `~/Games/Brutal Doom - Momentum`. Settings/saves remain in UZDoom's existing Flatpak data area; no forced display/input changes or persistent permission overrides.

## Before playing

Confirm Brutal Doom weapons/HUD, mouse aim/fire, movement, audio, desired display mode, save/relaunch and clean exit. The guide reports legacy script warnings but no fatal error for the base mod; that is not a gameplay certification. Test the optional Doom Metal soundtrack separately using --metal. Existing UZDoom settings are preserved.

## Optional Doom Metal

The soundtrack is included but disabled by default. Launch `~/.local/bin/brutal-doom --metal` to enable it after the base PK3. The normal Store library entry uses the guide's baseline.

## Exact setup

The guide explicitly excludes brutalVoxelDoom2.0Complete.pk3 because its UZDoom 5.0.1 parse test failed. No voxel package or unrelated addon is bundled or loaded.

Verify is read-only. Repair restores missing owned files from their exact original bytes and reports edits instead of overwriting them. Uninstall preserves original data, IWAD, saves, edits, unknown files, software, art and support. Reconcile interrupted jobs before retrying.
