# Brutal Doom: play checklist

Confirm Brutal Doom weapons/HUD, mouse aim/fire, movement, audio, desired display mode, save/relaunch and clean exit. The guide reports legacy script warnings but no fatal error for the base mod; that is not a gameplay certification. Test the optional Doom Metal soundtrack separately using --metal. Existing UZDoom settings are preserved.

## Optional Doom Metal

The soundtrack is included but disabled by default. Launch `~/.local/bin/brutal-doom --metal` to enable it after the base PK3. The normal Store library entry uses the guide's baseline.

The guide explicitly excludes brutalVoxelDoom2.0Complete.pk3 because its UZDoom 5.0.1 parse test failed. No voxel package or unrelated addon is bundled or loaded.

Set controls, display and audio in UZDoom's menus. Existing settings and saves are preserved. No automatic graphical/gameplay check is claimed.
