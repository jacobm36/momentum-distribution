VOXEL DUKE NUKEM 3D

===========================================================================================================================

Version 1.0
Released on November 21, 2025
Author: Daniel Peterson aka "Cheello"

===========================================================================================================================

ABOUT  

===========================================================================================================================

This mod replaces Duke Nukem 3D sprites (monsters, items, props, etc.) with 3d voxel models. It is designed for use with the 
eDuke32 source port only.  

===========================================================================================================================

INSTALLATION  

===========================================================================================================================

This mod works ONLY with eDuke32.

You will need Duke 3D's .GRP file to run (Version 1.3D, Plutonium/Atomic Edition, or 20th Anniversary World Tour).

1. Download the latest eDuke32 executable from https://www.eduke32.com/

2. Extract all eDuke32 files into a folder called "Duke 3D"

3. Place voxel_duke3d.zip into the "Duke 3D" folder, in a subfolder called "autoload".

4. Make sure that the autoload option is enabled in the eDuke32 launcher and voxels are turned on
in-game, by going to "Options", "Display Setup", and make sure "Voxels" are set to "On".

Alternatively, drag voxel_duke3d.zip onto the eduke32.exe file to load it automatically.

For the .GRP file, copy it from its original folder into your "Duke 3D" folder, where eduke32.exe is located.

For Duke Nukem 3D 20th Anniversary in Steam, right click on the title ---> Manage ---> Browse local files. Locate DUKE3D.GRP and copy it into your new Duke 3D folder.

===========================================================================================================================

NOTES  

===========================================================================================================================

This mod will NOT work correctly with the Raze port. Some voxels will not load in Raze, for some reason. 

This mod currently only supports the ORIGINAL 3 EPISODES. Atomic Edition episode "The Birth" will be completed at a later date.

DO NOT unzip this .zip file. Keep the .zip file intact and place it in the autoload folder inside of your Duke 3D folder.

Polymer rendering does not work with this mod! Leave the Polymer option unchecked, or it will not run!
