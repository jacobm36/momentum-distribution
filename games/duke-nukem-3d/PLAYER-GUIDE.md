# Duke Nukem 3D — play guide

Launch Duke Nukem 3D from Momentum or Applications after installation with a supporting runner. Choose a campaign episode and start a new game. Confirm movement, mouse aiming/fire and your preferred fullscreen/resolution in Options. Existing bindings are preserved.

Check sharper signs/walls, depth on covered voxel pickups/enemies, and recorded SC-55 music. Enable Polymost/OpenGL, high-resolution textures, voxels/models and music if imported settings differ. Keep Polymer off. The voxel release covers the original three episodes; complete Atomic Episode 4 coverage is not claimed.

Save, exit normally, relaunch from the same entry and load the save. Old engine-version saves may need the original working engine; keep originals. Verify is read-only; Repair recreates missing files but leaves edited files for reconciliation. Uninstall keeps game data, personal settings/saves and the shared engine.

If definitions fail to load, check both -g graphics archives and the corresponding -mh modules. If music remains MIDI, check local NoAutoLoad=0, startup autoload checkbox and volume. Do not install a competing full HRP or change the archive paths while testing this combination.
