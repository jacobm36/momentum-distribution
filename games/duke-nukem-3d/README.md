# Duke Nukem 3D

Come get some. Classic Duke, with dimensional voxels, sharper original-style
textures and recorded Roland SC-55 music. All three enhancement packs are included.

## Bring your Duke

Choose the folder containing **DUKE3D.GRP** from your registered original or
Atomic Edition copy. Optional **DUKE.RTS** and root settings/saves travel with it.
Shareware is not supported; World Tour and expansions need separate checks.

## Install with Momentum

**Add game > Duke Nukem 3D > Choose folder > Review > Install.**

Momentum reuses your compatible native EDuke32 without changing it. Missing
software uses separately approved preparation from pinned official source.
Compilation needs the Ubuntu prerequisites in the EDuke32 Linux build guide;
Momentum does not elevate or install system packages.

Default destination: `~/Games/Duke Nukem 3D - Momentum`. Your original folder,
engine and shared settings stay untouched.

## Duke it out

Check the game's Controls menu for movement, mouse aim and firing. Use Polymost,
Voxels On, High Resolution Textures On and Music On. Absent local settings receive
starting presets; existing preferences are preserved, not forced.

Choose your display settings, confirm all three packs in a campaign level, then
save, exit normally and test loading that save after relaunch. Atomic Edition's
fourth-episode voxel coverage is not promised.

## Keep it yours

Settings and saves live in this isolated game folder. Verify is read-only;
repair restores missing owned files and refuses edited managed files.
Uninstall keeps your base files, settings, saves, artwork and shared engine.
Retained-state reinstall brings the enhancements back without replacing saves.

Ubuntu 24.04 x86_64, exact approved native EDuke32 bytes. No alternative engine
fallback. Installer verification is separate from gameplay: your library entry
stays **setup required** pending controls, graphics, music and save/relaunch checks.
