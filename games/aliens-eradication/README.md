# Aliens: Eradication

Eight maps. Four classes. Stay frosty.

## Bring your game

Select a folder containing your licensed **DOOM2.WAD**. All guide-selected mod content and artwork are bundled; no mod downloads or engine choices. Commercial base data is not included.

## Install

**Add game > Aliens: Eradication > Choose folder > Review > Install.** Momentum prepares missing UZDoom after separate approval and copies your base files without changing originals.

Default destination: `~/Games/Aliens Eradication - Momentum`. Settings/saves remain in UZDoom's existing Flatpak data area; no forced display/input changes or persistent permission overrides.

## Before playing

Select a class and confirm the Eradication MAP01 campaign, not stock Doom II. Enable and bind mouse-look, jumping and crouching; the creator requires these for the mapset. Enable dynamic lights and use dark sector lighting for the intended atmosphere. Confirm aim/fire, movement, audio, desired display mode, save/relaunch and clean exit. Existing UZDoom settings are preserved.

## Exact setup

Only the guide-defined TC PK3 and eight-map campaign WAD are bundled, in that order. No other campaign, class addon or commercial IWAD is included.

Verify is read-only. Repair restores missing owned files from their exact original bytes and reports edits instead of overwriting them. Uninstall preserves original data, IWAD, saves, edits, unknown files, software, art and support. Reconcile interrupted jobs before retrying.
