# Ashes 2063: Enriched

Scavenge the ruins. Ride into the wasteland.

## Bring your game

Select a folder containing your licensed **DOOM2.WAD**. All guide-selected mod content and artwork are bundled; no mod downloads or engine choices. Commercial base data is not included.

## Install

**Add game > Ashes 2063: Enriched > Choose folder > Review > Install.** Momentum prepares missing UZDoom after separate approval and copies your base files without changing originals.

Default destination: `~/Games/Ashes 2063 - Momentum`. Settings/saves remain in UZDoom's existing Flatpak data area; no forced display/input changes or persistent permission overrides.

## Before playing

Confirm the Ashes title/menu and Enriched episode load, mouse aim/fire, movement, audio, comfortable controls/display, save/relaunch and clean exit. Existing UZDoom settings are preserved. This package uses the guide's Doom II baseline; Freedoom and its optional patch are not certified.

## Exact setup

Ashes2063EnrichedFDPatch.pk3 is not bundled or loaded because the guide does not establish its role for Doom II. game_support.pk3 and game_widescreen_gfx.pk3 are engine resources, not Ashes addons; UZDoom supplies its own. Other Ashes episodes and newer releases are not substituted.
