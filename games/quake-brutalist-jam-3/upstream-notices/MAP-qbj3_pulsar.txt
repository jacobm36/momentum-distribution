Title                   : The Monochorome
Filename                : qbj3_pulsar
Release date            : 08/12/2025
Author                  : Andrey 'PuLSaR' Sayenko
Email Address           : pulsar1337@gmail.com
Misc. Author Info       : I map from time to time and like to place spawns in quake maps

Description             : Medium-sized concrete map. It's actually a remix of my Map-Center retrojam 4 entry (The Hexagon Vault). It was very brutal so 			  	  I decided to redress it in the Makkon concrete texture set (with some textures by Strideh). But new weapons and monsters play so
			  differently that I had to rebalance the map entirely. I added a few brand new sections to the map in the end.
