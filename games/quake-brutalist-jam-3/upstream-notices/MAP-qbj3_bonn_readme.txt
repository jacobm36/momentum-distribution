Hello this is Bonn and this is my map for the 3rd edition of the quake brutalism jam.

---------------------------------------------------------------------------------------------------------------------------------

title:		Doomed to start again
file name:	qbj3_bonn
author:		Michał (Bonn) Chmiel

---------------------------------------------------------------------------------------------------------------------------------

	This map is vaugely inspired by the first two levels of Doom 2. It consists of a brutalistic building complex and an oustide area. The complex has two floors to it. The First floor is based loosely on Doom 2's E1M1 and the underground level is equally loosely based on Doom 2's E1M2. There are 5 secrets in total. 

I hope you'll enjoy it!
