# Quake Brutalist Jam III

Monumental concrete structures, a new arsenal and seventy-seven community maps.
Installer **0.1.0**, Ubuntu 24.04 x86_64. Gameplay confirmation is required.

## Bring your Quake

Choose **Add game > Quake Brutalist Jam III** in Momentum and select your
licensed Quake folder containing `id1/pak0.pak` and `id1/pak1.pak`.
Commercial game data is never included or downloaded.

Momentum reuses exact official **Ironwail 0.8.2** and its companion, or prepares
them for your account from the pinned official release after approval.
No engine choices, automatic upgrades, elevation or fallback engines.

**QBJ3 1.3 mod assets are not bundled** because upstream restricts redistribution.
An existing complete `qbj3` folder is reused read-only; choose a separate
extracted folder if needed. Otherwise review and approve the pinned
official-site-linked source download before the separate game installation.
Invalid or modified sources are preserved and need manual reconciliation.

The mod download is **2.7 GB**, extracting to **6.2 GB**, followed by a separate
installed copy. Allow about **17 GiB free** for a fresh setup. Exact archive
size/SHA-256 and the complete 1,937-file inventory are verified.
The mirror hash was observed, not publisher-signed. Downloads do not resume.

## State and verification

The default game is `~/Games/Quake - Brutalist Jam III`.
Launch flags are `-basedir <game> -game qbj3 -fullscreen +mlook`.
No start map is forced; use Singleplayer or load a save.
Settings/saves stay in the isolated game tree. Original sources remain unchanged.
Removal retains base copies, settings/saves, unknown/edited files, shared
software/source cache, artwork and support. Reinstall restores absent owned
files without resetting personal state.

Readiness remains **setup required**. Installer and read-only host checks do
not prove gameplay: confirm graphics, sound, mouse controls, save/load/relaunch
and clean exit. No engines were launched during installer validation.
